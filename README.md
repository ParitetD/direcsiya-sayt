# 🏛️ Дирекция национальных видов спорта Кыргызстана

Веб-сайт в этно-стиле для Дирекции национальных видов спорта — организации, занимающейся сохранением, развитием и популяризацией традиционных видов спорта народов Кыргызстана.

## 🌐 Страницы

| Страница | Описание |
|----------|----------|
| Главная | Слайдер, обратный отсчёт Игр кочевников, новости, виды спорта |
| Виды спорта | 6 национальных видов спорта с описаниями |
| Мероприятия | Соревнования, чемпионаты, семинары |
| Галерея | Фотографии по категориям с лайтбоксом |
| Новости | Лента новостей с фильтрацией |
| Спортсмены | Карточки спортсменов, тренеров, сотрудников |
| О нас | История, команда, миссия |
| Контакты | Форма обратной связи, карта |
| Админ-панель | CRUD-управление контентом (`/admin`) |

## 🛡️ Безопасность

- **JWT-авторизация** с bcrypt-хешированием паролей
- **Helmet** — защитные HTTP-заголовки
- **Rate Limiting** — защита от брутфорса (10 попыток / 15 мин)
- **XSS-защита** — санитизация всех данных от API перед вставкой в DOM
- **Env-конфигурация** — секреты вынесены в `.env`
- **CORS** — настраиваемые разрешённые origins

## ⚙️ Конфигурация

Создайте файл `.env` в корне проекта:

```env
JWT_SECRET=your-very-long-random-secret-key
PORT=3000
ADMIN_DEFAULT_PASSWORD=admin123
CORS_ORIGIN=*
```

> ⚠️ Обязательно измените `JWT_SECRET` и `ADMIN_DEFAULT_PASSWORD` для продакшена!

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Разработка (с автоперезагрузкой)
npm run dev

# Продакшен
npm start
```

Сервер запустится на `http://localhost:3000`

## 🎨 Дизайн

- **Этно-стиль**: цветовая палитра (терракота, золото, зелень, кыргызский синий)
- **Этнические орнаменты** и паттерны
- **Двуязычность**: русский / кыргызский на всех страницах
- **Адаптивный дизайн**: мобильные, планшеты, десктоп

## 🔑 Первый вход в админку

1. Откройте `http://localhost:3000/admin`
2. Логин: `admin`, пароль: из `.env` (по умолчанию `admin123`)
3. **Сразу смените пароль** после первого входа!
